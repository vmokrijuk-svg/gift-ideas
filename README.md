# 🎁 Идеи подарков — рабочие заметки

Личный органайзер идей для подарков близким и себе. Работает как PWA: открывается на iPhone, iPad и в браузере. Данные хранятся локально + резервная копия в GitHub.

**Живая версия:** https://vmokrijuk-svg.github.io/gift-ideas/
**Репозиторий:** https://github.com/vmokrijuk-svg/gift-ideas
**Текущая версия бэкапа (читается авто-загрузкой):**
https://raw.githubusercontent.com/vmokrijuk-svg/gift-ideas/main/ideas.json

---

## 1. Контекст задачи

Изначальная боль: идеи для подарков расползались по 5–6 местам — закладки в браузере, Apple Notes, Apple Tasks, Telegram «Избранное», Instagram. Нужно было единое место, где:
- есть структура: человек → повод → бюджет → цена;
- можно быстро добавить идею «на ходу»;
- карточки приятны глазу и понятны **без кучи фильтров**;
- поддерживаются ссылки, картинки, цены, заметки;
- есть напоминания о праздниках.

Ограничения среды:
- Основная работа — на **корпоративном MacBook** с заблокированными инструментами разработчика (нет Web Inspector, MDM может ограничивать доступ к файлам).
- Личные устройства — **iPhone + два iPad**.
- Тестирование — **на личных устройствах**, не на рабочем ноутбуке.

Стратегический выбор: **не использовать готовые приложения** (Wisht, Wishy, Moonsift), а собрать своё под конкретный сценарий.

## 2. Архитектура решения

**Фронтенд — статический сайт из трёх файлов:**
- `index.html` — разметка;
- `style.css` — внешний вид;
- `app.js` — вся логика.

**Хостинг — GitHub Pages**, публичный репозиторий `gift-ideas`, ветка `main`, корень.

**Данные:**
- Основное хранилище — `localStorage` браузера.
- Резервная копия — файл `ideas.json` в **корне** репозитория.
- Архивы — файлы `ideas-ГГГГ-ММ-ДД.json` в папке **`backups/`**.
- Синхронизация — **полуавтоматическая**:
  - при старте приложение само подтягивает `ideas.json` из GitHub (`raw.githubusercontent.com`) и сравнивает время модификации;
  - если в GitHub свежее — предлагает загрузить;
  - запись в GitHub вручную: **📤** → модальное окно с выбором (текущий файл или архив с датой) → скачивание → загрузка в GitHub.

**Почему не автоматическая запись:** статический сайт не имеет прав на запись в репозиторий без OAuth-прокси (Cloudflare Worker и т.п.). Отложено.

**PWA:** есть `manifest.json` с иконками 192 и 512 px. Устанавливается на iPhone/iPad через «Поделиться → На экран Домой», открывается в полноэкранном режиме.

**Web Share Target:** прописан в манифесте, но **на iOS не работает** — Apple не показывает PWA в системном меню «Поделиться». Обходной путь через iOS Shortcuts обсуждался, отложен. Пользователь пока вводит ссылки вручную.

## 3. Что реализовано

### Хранение и структура
- Карточки идей с полями: `id`, `person`, `occasion`, `date`, `budget`, `title`, `link`, `image`, `price`, `notes`, `bought`, `createdAt`, `updatedAt`.
- **Справочник людей** (`giftPeople`) — отдельный массив имён. Нельзя удалить человека, если у него есть идеи.
- **Фото людей** (`giftPeoplePhotos`) — объект `{ "Мама": "data:image/...", ... }`. Автосжатие до 200 px.
- Миграция: при первом запуске новой версии люди автоматически собираются из существующих карточек.
- Группировка карточек по людям. Люди сортируются **по количеству идей** (по убыванию), при равенстве — по алфавиту.
- **Сворачивание групп** по клику на заголовок. Состояние в `localStorage` (`giftCollapsedGroups`).

### Форма добавления / редактирования
- Одна форма на два режима: создание и редактирование (скрытое поле `id`).
- Человек выбирается из выпадающего списка + кнопка «+ Новый человек».
- Поле «Для кого» **обязательное**.
- Поле **«Дата праздника»** — необязательное, `<input type="date">` (на iPhone открывает нативный пикер).
- Поле **«Заметки»** — многострочное (`<textarea>`), для размера, цвета, где купить и т.п.
- Картинка: загрузка из галереи, автосжатие до 400 px и JPEG 0.7. Хранится как Base64 в поле `image`.

### Просмотр — две вкладки

**📋 Список:**
- Блок **🎂 Скоро** — ближайшие 5 праздников в пределах 90 дней. Группирует по человеку + дате.
- **Поиск** по имени, названию, поводу.
- **Фильтр** «Только не купленные».
- **Сортировка** внутри групп: по дате / по сумме.
- **Суммы:** общие в шапке `Всего: X ₽ · Не куплено: Y ₽`; в заголовке каждой группы `N идей · M куплено · Z ₽`.
- **Заметки в карточке** — обрезаны до 2 строк с многоточием (CSS `-webkit-line-clamp: 2`).
- **Купленные карточки** — приглушённые (`opacity: 0.6`, картинка в grayscale).

**📅 Календарь:**
- Компактная сетка месяца: 7 колонок, ячейки фиксированной высоты 38 px.
- `max-width: 520px`, центрирован — не растягивается на широком экране.
- Даты с событиями — бежевый фон + оранжевые точки (по количеству идей, до 3).
- Сегодняшний день — синий.
- Переключение месяцев стрелками. **Назад в прошлое нельзя** (стрелка заблокирована).
- Под сеткой — список событий месяца.
- Текущая вкладка запоминается в `localStorage` (`giftViewMode`).

### Экспорт / импорт / синхронизация
- Кнопка **📤** открывает модальное окно с тремя опциями:
  - **📤 Скачать `ideas.json`** — текущая версия, для корня репозитория.
  - **📦 Скачать архив с датой** — `ideas-2026-10-08.json`, для папки `backups/`.
  - **📥 Импортировать из файла** — загрузка JSON с устройства.
- При старте **авто-проверка GitHub**: если `lastModified` в `ideas.json` новее локального — предложение загрузить.
- Статус-бар под шапкой: «✓ Данные актуальны», «Локальные данные новее», «Офлайн-режим».

### Справочник людей
- Открывается по кнопке **⚙️** в шапке.
- У каждого: аватар (фото или первая буква имени), счётчик идей, кнопки 📷 (загрузить фото), ✕ (убрать фото), «Удалить».
- Удаление человека с идеями запрещено.

### Отладка
- **Видимый журнал** (`#debug-log`) — работает без Web Inspector. Ловит `window.onerror`, логирует ключевые события.
- Показывается автоматически при критической ошибке.

## 4. Ключевые технические решения

**Никаких фреймворков.** Чистый HTML + CSS + JS. Работает и при `file://`, и на GitHub Pages.

**LocalStorage, а не IndexedDB.** Данных мало. Лимит ~5 МБ, но при сжатии картинок до 400 px JPEG 0.7 каждая весит 15–40 КБ — влезает 100+ штук. Фото людей ещё меньше (200 px).

**Один `app.js` без модулей.** Работает везде одинаково.

**Inline-обработчики `onclick` в HTML** — там, где важно, чтобы действие сработало даже при падении скрипта. Для полей ввода, которые «оживают» до загрузки `app.js` (поиск, чекбоксы), — только `addEventListener`.

**Полуавтоматическая синхронизация.** Компромисс: чтение автоматическое, запись — вручную.

**`resetImageField()` — отдельная функция.** Решает баг Safari: `form.reset()` не сбрасывает скрытые поля и `input[type=file]`. Функция вызывается в `openForm`, `closeForm` и `editIdea`.

## 5. Известные ограничения

- **Данные не синхронизируются между устройствами мгновенно.** Разные iPhone/iPad видят разные LocalStorage, синхронизация — через GitHub при следующем открытии.
- **LocalStorage привязан к браузеру.** Очистка кэша Safari = потеря локальных данных (если нет свежего `ideas.json`).
- **Автоматической записи в GitHub нет.**
- **Корпоративный MacBook не подходит для тестирования.**
- **Web Share Target на iOS не работает** — Apple не показывает PWA в системном меню «Поделиться». Обходной путь — iOS Shortcuts (не настроен).

## 8. Как обновлять приложение

1. Правки вносятся **на корпоративном MacBook** (там удобный редактор).
2. Файлы загружаются в репозиторий GitHub через веб-интерфейс.
3. На iPhone/iPad: открыть сайт → **Cmd + Option + E** (очистка кэша) → **Cmd + Shift + R** (жёсткая перезагрузка).

**Важно про GitHub Pages:** если залить 4 файла сразу, GitHub может запустить две сборки параллельно и одну отменить. Это нормально — просто подождите и проверьте вкладку **Actions**, там должна быть зелёная галочка у последнего workflow.

**Если что-то сломалось:** открыть приложение, посмотреть журнал внизу экрана. Если журнала нет — ошибка некритическая. Если есть — прочитать текст.

**Если данные пропали:** проверить `ideas.json` в репозитории. Если там свежая версия — при следующем открытии приложение предложит её загрузить. Если нет — восстановить из `backups/` через 📥 Импорт.

## 10. Как делать бэкапы

**Текущая версия (`ideas.json` в корне):**
- Обновлять каждый раз после крупных изменений.
- 📤 → **📤 Скачать `ideas.json`** → загрузить в корень репозитория.

**Архив (`backups/ideas-ГГГГ-ММ-ДД.json`):**
- Раз в неделю/месяц или перед крупными экспериментами.
- 📤 → **📦 Скачать архив с датой** → загрузить в папку `backups/`.

**Имя файла** генерируется автоматически: дата берётся из устройства в момент нажатия кнопки.

**Откат из архива:**
1. Открыть нужный файл в `backups/` на GitHub → **Download raw file**.
2. Открыть приложение → 📤 → **📥 Импортировать из файла**.
3. Выбрать скачанный файл — данные восстановятся.

## 12. На чём спотыкались (полезно помнить)

- **Форма не закрывалась** — виноват `form.reset()` в Safari + кнопка без `type="button"`. Решение: inline-обработчики + явные `type`.
- **Картинка «прилипала» к следующим идеям** — `form.reset()` не сбрасывает скрытые поля. Решение: `resetImageField()` в `openForm`/`closeForm`/`editIdea`.
- **`onSearchInput` не находился при загрузке** — браузер восстанавливал значение поля поиска и вызывал обработчик до загрузки `app.js`. Решение: `addEventListener` в `start()`.
- **GitHub Pages `Cancelled after 22s`** — не ошибка, а отмена промежуточной сборки. Загружать файлы по одному с паузой.
- **Web Share Target на iOS** — не работает, несмотря на корректный манифест. Это ограничение WebKit, не кода.
- **Календарь растягивался** — `aspect-ratio: 1` на широких экранах. Решение: `max-width: 520px` + фиксированная высота ячейки.
